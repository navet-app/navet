Layout packs provide a starting arrangement. They remain ordinary editable Home layouts after
being applied.

## Before applying a pack

Export a backup if the current layout matters. A pack can replace or substantially rearrange the
active Home dashboard.

## Apply a pack

1. Open the target Home dashboard.
2. Choose **Customize**.
3. Open **Presets** in the editing bar, or under **More actions** on a smaller screen.
4. Choose **Command center**, **Security monitor**, or **Energy wall**.
5. Read the confirmation, then choose **Apply preset** to rearrange the active Home dashboard.

To arrange cards yourself, use the editing bar's layout and section controls instead of applying
a preset.

## Refine the result

After applying a pack:

- Move or resize cards.
- Remove content that is not useful on this dashboard.
- Add missing provider entities or widgets.
- Lock stable cards.
- Use **Undo** while the edit history is still available.

## Use packs with multiple dashboards

Create a focused dashboard first, then apply the pack there. This preserves the default dashboard
while you evaluate the result.

## If a pack has empty areas

The pack can only show content available from the selected providers. Add an equivalent card
manually, or choose a pack aligned with the capabilities currently available.
